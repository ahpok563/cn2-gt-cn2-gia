## CN2 GT、CN2 GIA、三网CN2 GIA：先把这三个词分清

中国电信有三张承载网：传统163骨干网、CN2 GT、CN2 GIA。三者的差别落在出口节点上。

163骨干网最慢，走的是传统路由。CN2 GT保证国际出口走高速的59.43节点，但省级出口仍然是传统的202.97节点。CN2 GIA则省级出口和国际出口都走59.43节点。说白一点，GT是半程优化，GIA是全程优化。

这个区别在早几年不算致命，现在不一样了。CN2 GT线路本身也很拥挤，晚高峰的表现不比163骨干网好多少。所以真要拉开晚高峰的差距，得看GIA这一档。GIA提供专属国际带宽和优先路由，延迟最低、丢包最小，价格也比GT贵出一截。

三网CN2 GIA是另一层概念。CN2是电信的线路，但联通和移动可以在国内接入电信网络，之后走CN2节点出境，这样联通、移动用户也能吃到CN2的回程。商家标“三网CN2 GIA”，说的就是这个。标了这三个字，意味着电信、联通、移动三家的回程都走CN2，而不是只有电信走。

再往下还有去程和回程的区别。去程是你本地到服务器，回程是服务器回你本地。打开一个网页、下载一个文件，数据要来回跑，回程直接决定页面加载和下载速度。不少方案只做回程CN2 GIA，去程走普通线路，日常用起来也够。判断标准很简单：回程CN2 GIA比去程更重要，双程都走CN2 GIA最好。

机房位置也值得说一句。美西的CN2 GIA主要有两个落脚点，洛杉矶和圣何塞。洛杉矶的选择更多，多数人默认选洛杉矶。六六云的美国节点也在洛杉矶。

差距不小。GIA提供专属国际带宽，性能显著高于GT，价格也贵很多。更关键的是GT现在也拥挤，晚高峰不比163骨干网好多少，预算够就直接上GIA，预算不够也别指望GT能解决晚高峰问题。

**回程CN2 GIA和双向CN2 GIA，哪个更重要？**

回程更重要。回程决定服务器到你本地的速度，也就是网页加载和文件下载的快慢。去程影响的是你上传的速度，日常用到的频率低一些。双程都是CN2 GIA当然最好，预算有限时优先保回程。

可以，但要看有没有国内访问需求。站群如果没有国内访客，普通美西服务器更划算，同样的钱能买到更多IP和更大带宽。有国内访客、又要多站点，才值得为CN2付溢价。
